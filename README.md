# TaskOrganizer

**A simple JavaFX application for managing your tasks efficiently.**

## Features

- **Add Tasks**: Easily add new tasks to your list.
- **Update Tasks**: Modify existing tasks with updated information.
- **Delete Tasks**: Remove tasks that are no longer needed.
- **Store Tasks**: Keep your tasks stored securely.
- **Display and Organize**: View and organize your tasks for better management.

## Default Login

To access the app, use the following default login credentials:

- **Username**: `admin`
- **Password**: `1234`

## How to Run

You can find the executable `.jar` file in the following directory:

- `TaskOrganizer/TaskOrganizer.jar`

Simply run this file to start using the application.

## Build Instructions

To build and run the application on your PC, ensure that you have JavaFX installed and properly configured.
